Первый этап проекта включает в себя создание инфраструктуры для будущего придложени, целью которого будет является упралвение распределительным центром.
На данном этапе в приложени:
- запущен PostgreSQL в Docker
- подключён Swagger для документации API
- реализован Health endpoint для мониторинга
- Бд мигрирует
  На данном этапе приложение работает и готово к совершенствованию.
